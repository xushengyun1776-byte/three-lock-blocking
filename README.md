# three-lock-blocking

> AI 多人群像 / 一镜到底的站位与场景一致性控场技能 · AI Agent Skill

一套解决「同一空间里多角色 AI 一镜到底」站位漂移、错脸、长镜后段崩坏的控场方法：**三锁控场法（好莱坞群像控场法）**。把角色、空间、摄影机路径先变成可复用资产，再让模型生成最终表演；崩了的时段只局部重拍。

**实战来源**：抖音「三锁控场法」教程（创作者原视频 B 站 BV1XggH63EeM，附逐字提示词范例），2026-11-02 学习并技能化。

---

## 这是什么

不是"提示词合集"，而是把控场拆成**可复用资产 + 铁律**的流水线：

| 解决的问题 | 做法（对应锁） |
| -- | -- |
| 多人同框错脸 / 借脸 | **锁一 角色身份**：三视图资产 + C1–C6 编号，只声明一次 |
| 站位漂移（右侧人跑左侧、切回全员重排） | **锁二 空间关系**：俯视站位图，中后段不重描整房 |
| 30s 长镜后段崩 | **锁三 摄影机路径**：白模预演（Blender / 手机手持）+ 精确时间码，越靠后越局部 |
| 整条重抽成本高 | **局部重拍协议**：只修崩的几秒，保住已成立镜头 |

## 三锁 + 五维 + 局部重拍

- **三锁**：角色身份锁、空间关系锁、摄影机路径锁
- **五维提示词**：运镜锚定 / 角色声明 / 摄影灯光 / 当前状态 / 时间码（顺序即权重）
- **局部重拍**：修复提示只补三件事——起始状态、具体问题、接回原片

## 快速开始

```bash
# 1. 看结构化输入示例
python scripts/assemble_prompt.py --sample

# 2. 把自己的角色/站位/运镜/时间码填进 JSON，组装五维提示词
python scripts/assemble_prompt.py --in my_scene.json --out my_prompt.txt

# 3. 把 my_prompt.txt + 白模预演参考，喂给即梦图生视频 / H3 本地出片
```

## 关键纪律（红线）

1. C1–C6 只在前部声明一次，后续镜头不重描全角色
2. 站位锁定后，中后段提示词不重描整房
3. 时间码越靠后越局部、越具体，不重复整套空间设定
4. 白模预演不追求最终质感，只验证空间 / 节奏 / 路径
