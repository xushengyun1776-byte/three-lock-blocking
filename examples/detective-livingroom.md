# 范例：侦探庄园客厅 — 单镜到底群像长镜（30s）

> 本范例完整复现原视频示例场景，演示三锁控场法从资产到出片的每一步。
> 场景：同一庄园客厅里反复穿插多名角色，镜头移动期间人物站位与空间关系始终连续。

---

## 锁二：俯视站位图（top-down staging）

```
           壁炉
            |
   [C5 朱利安]       窗
            |
  ---------------------------------
  |                               |
  |   红长沙发(C1 伊芙)    书桌    |
  |        (面朝房间中央)   (C2?)  |
  |                               |
  ---------------------------------
            门
   [C6 管家]            [C3 亚瑟 未出镜，在画外左侧]
```

文字版锚定（写入提示词 D2）：**图片3作为场景中人物站位锚定**——C1 在红长沙发、C5 在壁炉前、C3 在画外左侧、C6 在门口。

> 站位锁定后，后续 0–4s / 4–7s 等分段时间码**不再重描整房**，只描述当前变化。

## 锁三a：白模预演路径（previz）

镜头轨迹（俯视→特写→群像）：
1. 鞋和脚踝特写（低位起手）
2. 沿腿部上移到角色面部
3. 越过人物带出背后另一名角色
4. 进入整间客厅群像

本地落地：Blender 摆方块按上图站位，K 帧走这条路径渲染 `previz.mp4`；或手机绕真实客厅走一圈录手持运镜当运动参考。

## 锁三b + D5：精确时间码 beats（越靠后越局部）

| 时间码 | 画面 / 表演 / 对白 |
|--------|--------------------|
| 0.00–4.00 | 第一帧镜头位于红长沙发背后缓慢前推。前景右侧是 C1 伊芙（图片4）的肩膀、侧脸与上半身，背景左侧是站在壁炉前的 C5 朱利安（图片8）。C1 坐在沙发上面向房间中央，头与眼睛转向画面左侧，与未出镜的 C3 亚瑟争吵。 |
| 4.00–7.00 | 抬到 C1 脸部特写，带出背后入画的 C4 薇拉（图片7）。 |
| 7.00–15.00 | 越过 C1 进入整间客厅群像，C2 丹尼尔（图片5）从书桌起身，C6 管家（图片9）在门口保持静止。 |
| 15.00–30.00 | 镜头缓慢环绕，保持所有人站位不变，收尾落在 C1 与 C5 的对峙关系上。 |

## 出片与修复

- **出片**：把 `previz.mp4` 作为运动参考 + `detective_prompt.txt` 作为提示词，走即梦图生视频（一镜到底）或 H3 本地出片（按时间码分段）。
- **修复**：若 15–30s 段环绕时 C2 站位移位，框选该段局部重拍，修复提示只补三件事——起始状态（C2 在书桌旁）、具体问题（站位漂移）、接回原片（收尾回到 C1–C5 对峙）。保住前 15s 已成立镜头。
